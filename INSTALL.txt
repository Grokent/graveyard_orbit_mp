GRAVEYARD ORBIT — CO-OP MOD (MP BUILD 16)
=========================================

WHAT THIS IS
  A co-op mod for Graveyard Orbit: Steam lobby, friend invites and a shared
  contract picker. Up to 4 players. Everyone needs this mod installed.

REQUIREMENTS
  - Windows 10/11, or Linux / Steam Deck (Proton)
  - Graveyard Orbit installed through Steam (AppID 4654120)

INSTALL (SAME ON WINDOWS AND LINUX)
  1. Close Graveyard Orbit.
  2. In Steam, right-click Graveyard Orbit > Manage > Browse local files.
     That opens the game folder (the one containing GraveyardOrbit.exe).
  3. Download the release zip:
       https://github.com/Grokent/graveyard_orbit_mp/releases/latest/download/GraveyardOrbit-Co-op-0.1.0-MP16.zip
  4. Extract EVERYTHING from the zip into the game folder that opened in step 2.
     It only adds files; nothing in the original game is replaced:
       winhttp.dll
       doorstop_config.ini
       .doorstop_version
       changelog.txt
       BepInEx/...
       Report.bat / Report.ps1 / Report.sh
  5. Linux / Steam Deck (Proton) ONLY: add this launch option once
     (game > Properties > Launch Options):
       WINEDLLOVERRIDES="winhttp=n,b" %command%
     Windows needs no launch options.
  6. Launch the game through Steam normally.

USING IT
  - Title screen: MULTIPLAYER (between NEW GAME and SETTINGS).
  - Opening it hosts a friends-only Steam lobby and shows your online friends.
  - INVITE OTHERS opens the Steam invite dialog; each friend row has its own
    INVITE button. Invites carry a lobby connect string, so the friend joins
    whether their game is already running or closed.
  - Your friend accepts the Steam invite; the lobby opens for them automatically.
  - The host picks a contract and presses START. Clients automatically
    receive the host's save and load the game with them. The client's previous
    save is backed up next to it as graveyard_orbit_save.json.coop-backup.
  - Each player launches and returns to base independently. Clearing the
    structure is mirrored to everyone.

CURRENT TEST LIMITATIONS
  - The host's save is the session's save; clients play the host's base and
    ship. Progression changes on clients are local and are not synced back.
  - Map layout, materials and seeded enemies are shared (the session seeds
    travel with the host save).
  - Player weapon fire (projectiles, probes and beams) is mirrored to the other
    players. Damage is resolved on each machine.
  - Enemies are host-authoritative for HP/death: the host broadcasts snapshots,
    clients apply them and forward their damage to the host. Each player's own
    EnemyManager still simulates attacks locally, so turrets, spiral shots and
    attack swarms engage the host and every client equally.
  - Enemy shots on clients use the host's real projectile VFX and deal damage.
  - Destroyed tiles are synchronized and stay destroyed even if the other
    player is back in the base while they are broken; tile HP/crack state is
    still local.
  - Dropped loot is broadcast so every player sees the same resource motes, but
    each player collects their own.
  - Player deaths are broadcast: the destroyed ship disappears for everyone
    and reappears only when that player relaunches.
  - Enemy attack cooldowns and swarm units are simulated per player, so swarm
    instances are not bit-identical between machines.

LOGS / SETTINGS
  Log:      BepInEx/LogOutput.log
  Settings: BepInEx/config/agentbox.graveyardorbit.coop.cfg

MULTIPLAYER BUILD NUMBER
  This package is MP BUILD 16. The build is shown on the MULTIPLAYER menu entry
  and in the lobby header. Both players must run the same build; if they do not,
  the lobby shows a red BUILD MISMATCH warning and START is disabled.

SEND A REPORT
  If something goes wrong, close the game and run the bundled collector:
    Windows:            double-click Report.bat
    Linux / Steam Deck: ./Report.sh
  It collects the log, config, save seed summary and system info into a single
  archive on your Desktop / in your home folder named
  GraveyardOrbit-Co-op-Report-<date>. Send that archive to the developer.

UNINSTALL
  Delete these from the game folder:
    winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt, BepInEx/

NOTE
  BepInEx injects through winhttp.dll. Some antivirus tools may flag it as a
  false positive; that file is part of the standard BepInEx mod loader.
  Graveyard Orbit and all related content belong to Anchorhead Games.
